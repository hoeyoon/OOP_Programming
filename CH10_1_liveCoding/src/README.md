# OJ CH10_1_liveCoding

### 문제 설명
```
배열의 값을 입력받아 가장 작은 값을 리턴하는 제네릭 함수 smallest()를 예제 입/출력에 맞게 구현하라.
```

### 실행 결과
```
예제 - 1
<출력> 정수 6개를 입력하세요: <입력> 10 5 8 3 6 2
<출력> 가장 작은 정수는: 2
<출력> 실수 6개를 입력하세요: <입력> 3.5 1.2 5.7 2.8 4.1 0.9
<출력> 가장 작은 실수는: 0.9

예제 - 2
<출력> 정수 6개를 입력하세요: <입력> 7 4 9 2 4 6
<출력> 가장 작은 정수는: 2
<출력> 실수 6개를 입력하세요: <입력> -2.5 1.8 -3.2 0.7 2.1 -1.5
<출력> 가장 작은 실수는: -3.2

예제 - 3
<출력> 정수 6개를 입력하세요: <입력> 5 5 5 5 5 5
<출력> 가장 작은 정수는: 5
<출력> 실수 6개를 입력하세요: <입력> 4.6 4.6 4.6 4.6 4.6 4.6
<출력> 가장 작은 실수는: 4.6

```
